# docs

`docs/` holds decisions about the product: the plan, the TODO list, feature and screen specs, design, build briefs and
reviews, all in [v2/](v2/README.md) (start at [v2/PLAN.md](v2/PLAN.md)). Superseded documents kept for their ideas are in
`archive/v1/`; nothing live links into it.

Research does not live here. The method, the per-type checklists, output formats, raw captures, per-trip findings, run notes,
audits and research reports are all in the root [research/](../research/README.md) (cleanup D11). Until CLN-R,
`v2/research/` still holds the generated capture checklists, the research backlog and the tag-conflict report, plus a stub
README that maps old research paths to new ones. `PLAN-platform.md`, `PLAN-locations-g5.md` and `GLOBE-RESEARCH.md` leave in
CLN-2.
