Goal (owner, 27 Oct 2026): finish the three clickable prototypes by fixing every finding in
[FINDINGS-2026-10-27.md](FINDINGS-2026-10-27.md) that a prototype can fix, so they are done and not left half-way. The other

8, 9, 11, 12, 20, 21, 22, 25, 26 (the automated part), 27 (as prototype specs), and the infra notes (as docs and a checklist).

map tiles (the prototype has no network), account sync and sign-in, budget bands (price coverage), school holidays, camper and

**Owner actions** (not done by an agent): edit or remove `~/.cloudflared/config.yml`; choose a permanent named hostname with
Cloudflare Access; test on a real phone; the gap list (R-280).

## Phases and order

Phase 0 is one agent and a prerequisite; phases 1 to 3 run after it. Agents in the same phase have disjoint files.

### Phase 0: shared pieces (1 agent, Sonnet, about 1 h)
Folder `docs/v2/prototypes/shared/`:
- `sun.js`: port of `core/src/sun`; test file compares 6 fixed cases (incl. Reykjavik, Banff, Cortina, Toronto, a polar edge) to `node core/bin/sun.ts` output within 1 minute.
- `contract.js`: one definition of the `proto.trips` shape, `normalise(trip)` (month as number or `YYYY-MM`, missing fields), `validate(trip)`; used by builder and planner on every read and write (fixes the class of bug B3).
- `ics.js`: timed events per item and all-day book-by events (fixes planner finding "all-day only").
- `map.js`: one SVG map renderer: day-coloured legs, numbered pins, tap pin to open an item, park outline; used by builder, parks and planner (replaces three different placeholders).
- `engine-api.md`: the builder engine's public functions (`build`, `rebuild`, `fillFree`, `fits`) so the planner can re-flow; builder moves `engine.js` to `shared/engine.js` (planner then imports it).
- `tests/`: Playwright setup, `serve` helper, contrast checker (computed styles in light and dark for every text and control pair, report below 4.5:1 text and 3:1 controls), keyboard-only walker, `getByRole` accessibility-tree dump per page.
- Folder contract, gate map and hardcode ratchet pass.
