A public, read-only site: no login, nothing private. Search, a globe, trip pages and place pages. Trips are dateless. Everything is read from JSON data files and built into static pages.

## 7. Risks to the date

1. **Stage 5 finds something big.** A privacy or P8 finding would add a day. The reviews so far found none in the built output.
2. **Your review finds design changes.** Small ones are hours. A new feature is a new lane.
3. **Machine load.** Parallel builders make timing tests flaky; the final runs are on a quiet machine.
4. **Merging into main.** main is the live old site. The merge is one merge commit so it reverts as one; Pages keeps the previous deployment for an instant rollback. 301s cached by browsers and search indexing cannot be undone, which is why the old pages get a temporary redirect first.
