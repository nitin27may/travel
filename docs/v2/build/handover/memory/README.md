# Owner memory, copied into the repo

These are the working-memory notes that guided the work on one machine (the Claude memory folder `~/.claude/projects/.../memory/`). They are copied here so another machine, or a fresh Claude session, can read them. They record the owner's decisions and working rules, each with the reason. They contain no secrets. Where a note is older than `docs/v2/build/public-site/STATUS.md`, STATUS wins.

To restore them as live memory on the other machine, copy the `*.md` files (not this README) into that machine's Claude memory folder for this project and add one line per file to its `MEMORY.md` index.
