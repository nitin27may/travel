bugs). Section 7 keeps the prototype findings already made, marked "prototype, flow only, not to be fixed".

## How it was run

- `web/` built as a server build in the worktree (`pnpm build`, then `next start -p 4353`) with `HOME_POINT_LAT=10.5`,
  `HOME_POINT_LON=-140.5` (decoy), `NEXT_PUBLIC_TRIP_EDIT=1`; sign-in and account trips off (no secrets; a device copy is fully
  usable signed out, EM8). No `.env.local` copied.
- Playwright from `web/node_modules`, Chromium with `--use-gl=angle --use-angle=metal --ignore-gpu-blocklist
  --enable-gpu-rasterization`, device scale 2, 390 x 844 and 1440 x 900, light and dark set through the site's own theme
  control (`Switch to dark theme`). Tall pages read as viewport tiles while scrolling, so sticky rows show as a person sees them.
- Screenshots: `/Users/nks/workspace/travel-wt/S2-SWEEP-shots/` (real app), `.../S2-SWEEP-shots/prototype/` (prototype). File
  names end in `-<width>-<theme>.png`; `-tN` is the Nth scroll tile, `-sN` the Nth tile inside a sheet.
- Flows driven: public trip (Summary, Days, Stops) for Canadian Rockies and Dolomites; Copy to my trips (date, party, done step,
  Undo, Open in Mine); Mine list and row menu; own trip `/t/<id>/` (Summary, Days, sticky identity); Edit trip (Trip settings
  sheet: name, start, adults, children, pace); Add a place to Day n; the day version menu.
- Console: no page errors on any route. Only warnings: Next CSS chunks "preloaded but not used" (SW-024) and aborted map tile
  requests while the map pans (expected, not a defect).

Severity: **blocker** stops the flow; **major** a family would hit it and be misled or slowed; **minor** polish or consistency.

## 6. Works well

- The Days tab is the chronological day view, on both `/trips/` and `/t/`: time rail with estimates, a leg row between every two
  stops, meals, rest, sunset and the drive back in order; day header with base, window and sun range.
- The own page reuses the public page's timeline, map column and tabs, so a copy reads exactly like our plan (one renderer).
- Sticky identity on `/t/`: the identity cell and title stay in the stuck row at 1440 and 390 (scenario rule 1).
- Copy sheet: calendar with weekend, long weekend, school break and trip-season marks; party steppers 44 px; Undo on the done step.
- Kicker words and sync word follow the vocabulary ("Your copy · from our … trip", "On this device"); the settings foot reads
  "Kept in this browser. Sign in to keep it on every device." exactly as specified.
- Colour: nothing outside `themes.css` seen; no green, no purple, no emojis. Contrast checked and passing: Check warning text
  rgb 122,82,0 on white **6.92:1** (light) and rgb 224,177,92 on rgb 22,32,44 **8.31:1** (dark); leg text rgb 43,55,70 on white
  **12.09:1**.
- Day version menu states each version's consequence ("6.3 mi walking · 20 min driving · 07:50 to 19:00").
- No page errors in any route or flow at any width or theme.
