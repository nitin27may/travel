<section class="intro" id="about">
  <p class="kick">Before day one</p>
  <h2>What you are actually going to see</h2>
  <div class="lead">
    <p>The Green Mountains are old — Appalachian rock, folded up something like 400 million years ago, then worn down by erosion and scraped over by ice sheets. That history is why they look the way they do: rounded, forested right over the summits, more ridge than peak. Vermont is roughly three-quarters woodland, and it is the trees rather than the rock that do the work here.</p>
    <p>What makes the state famous in October is one species. <b>Sugar maple</b> dominates these hillsides in a way it does not anywhere else, and it turns orange and scarlet rather than the flat yellow that birch and aspen give the western ranges. The same tree pays the bills the rest of the year — Vermont produces around half of all the maple syrup in the United States.</p>
    <p>Peak color is not a date, it is a wave. It moves from north to south and from high ground down into the valleys over about three weeks, which is why this trip is built around a conditions check two days before you leave rather than a fixed plan. <b>October 1–4 puts you in the Northeast Kingdom's window</b> — the northernmost, highest and coldest corner, and reliably the first to turn.</p>

  <ul class="know">
    <li><b>1</b><span><b>Peak color is a moving target.</b> A scheduled check on September 29 emails a foliage, weather and road report ending in one verdict — keep the plan, swap Friday and Saturday, or fall back to Route 100. Read that before you drive.</span></li>
    <li><b>2</b><span><b>The trailhead lots are tiny.</b> Stowe Pinnacle holds about nine cars and fills before nine on an October weekend &mdash; and its overflow lot is a mile away by road, not next door. That constraint, not the map, sets the order of every day.</span></li>
    <li><b>3</b><span><b>Smugglers' Notch is a road, not a hike.</b> It threads between fallen boulders on tight switchbacks, closes for winter, and is open in early October. No trailers, no RVs.</span></li>
    <li><b>4</b><span><b>Expect 61&deg;F (16&deg;C) by day and near 40&deg;F (4&deg;C) at night &mdash; and much colder up high.</b> Early October in Stowe averages a high of <b>61&deg;F (16&deg;C)</b> falling to a low of <b>40&ndash;43&deg;F (4&ndash;6&deg;C)</b>, with about a <b>32&#37; chance of a wet day</b>. The summit of Mansfield runs roughly 12&deg;F colder than the village &mdash; that is a <b>6.7&deg;C</b> drop, not a 12-degree one &mdash; so the gondola top is near <b>49&deg;F (9&deg;C) by day and freezing at dawn</b> &mdash; people step out of the cabin in a t-shirt and regret it. Daylight is down to 11 h 43 m, sunrise 6:48, sunset 6:31.</span></li>
    <li><b>5</b><span><b>Only two days involve real driving.</b> The 660&nbsp;km run down on Thursday and the same back on Sunday, about 6h40 behind the wheel each way before the border and stops. Friday and Saturday are loops from one base &mdash; Stowe village is 18 minutes away, and the whole Northeast Kingdom circuit on Saturday is about 150&nbsp;km with no leg longer than about an hour. You unpack once.</span></li>
    <li><b>6</b><span><b>Sunset is early and it comes fast.</b> The light that makes these hills worth photographing lasts about forty minutes, and the last hour of any day should be somewhere you meant to be.</span></li>
  </ul>

          days === 1 ? "Tomorrow" :
          days === 0 ? "Today" :
          days > -7 ? "Trip week" : "Trip complete";
      }
      if (num) {
        num.textContent = days > 1 ? days.toLocaleString() + " days"
                        : days === 1 ? "1 day" : days === 0 ? "today" : "—";
      }
    }
    tick();
    setInterval(tick, 60000);
  })();

  /* ---- checklist persistence -------------------------------------------------------
     Supports #checklist input[data-k] and the older [data-ck] convention. For [data-ck]
     the previous per-page key is read as a fallback so ticks already made by the user
     survive the migration.                                                             */
  (function () {
    function bind(box, id) {
      var key = slug + ":" + id;
      var legacy = legacyPrefix ? legacyPrefix + id : null;
      try {
        var v = localStorage.getItem(key);
        if (v === null && legacy) v = localStorage.getItem(legacy);
        if (v === "1") {
          box.checked = true;
          if (box.parentElement) box.parentElement.classList.add("done");
        }
      } catch (e) { /* private mode */ }
      box.addEventListener("change", function () {
        if (box.parentElement) box.parentElement.classList.toggle("done", box.checked);
        try { localStorage.setItem(key, box.checked ? "1" : "0"); } catch (e) {}
      });
    }
    document.querySelectorAll("#checklist input[type=checkbox]").forEach(function (b) {
      bind(b, b.dataset.k || b.id || "");
    });
    document.querySelectorAll("[data-ck]").forEach(function (b) {
      bind(b, b.dataset.ck);
    });
  })();

  /* ---- scrollspy -------------------------------------------------------------------
     Marks both `active` and `on` — the two families used different class names — and
     scrolls the active item into view in the horizontally-scrolling nav, which the older
     pages did and the newer ones did not. Worth having everywhere.                      */
  (function () {
    if (!("IntersectionObserver" in window)) return;
    var links = [].slice.call(document.querySelectorAll("nav a[href^='#']"));
    if (!links.length) return;
    var sections = links
      .map(function (a) { return document.querySelector(a.getAttribute("href")); })
      .filter(Boolean);
    if (!sections.length) return;

    var obs = new IntersectionObserver(function (entries) {
      entries.forEach(function (e) {
        if (!e.isIntersecting) return;
        links.forEach(function (a) {
          var hit = a.getAttribute("href") === "#" + e.target.id;
          a.classList.toggle("active", hit);
          a.classList.toggle("on", hit);
          if (hit && a.scrollIntoView) {
            a.scrollIntoView({ block: "nearest", inline: "center", behavior: "smooth" });
          }
        });
      });
    }, { rootMargin: "-40% 0px -55% 0px" });

    sections.forEach(function (s) { obs.observe(s); });
  })();

  /* ---- A/B plan toggle -------------------------------------------------------------- */
  (function () {
    var buttons = document.querySelectorAll("[data-plan-btn]");
    if (!buttons.length) return;
    var key = slug + ":plan";

    function setPlan(which) {
      document.querySelectorAll("[data-plan]").forEach(function (panel) {
        panel.classList.toggle("show", panel.dataset.plan === which);
      });
      document.querySelectorAll("[data-plan-btn]").forEach(function (btn) {
        btn.classList.toggle("on", btn.dataset.planBtn === which);
      });
      try { localStorage.setItem(key, which); } catch (e) {}
    }

    buttons.forEach(function (btn) {
      btn.addEventListener("click", function () { setPlan(btn.dataset.planBtn); });
    });

    var saved = null;
    try { saved = localStorage.getItem(key); } catch (e) {}
    setPlan(saved || buttons[0].dataset.planBtn);
  })();
})();

</script>
