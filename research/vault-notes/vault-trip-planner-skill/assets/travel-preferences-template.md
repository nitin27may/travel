# Travel Preferences

> Defaults the trip-planner reads so local day trips and getaways need almost no setup. Edit anytime.

## Home base

- **Start address / city:** HOME BASE (e.g. Whitby, ON, Canada)
- **Default day-trip radius:** ~1.5-2 hrs drive
- **Usual transport:** car (note GO Train / VIA Rail options when relevant)

## Who travels

- TRAVELLER — role/age (e.g. self, partner, kid age 9)
- Default group size: N

## Defaults

- **Budget style:** mid-range / budget / splurge — and rough per-day comfort number
- **Pace:** packed / balanced / slow
- **Interests:** e.g. nature, scenic drives, easy hikes, food, family-friendly, hidden gems
- **Dietary:** any notes
- **Avoid:** anything that's a no (long flights, extreme heat, crowds, etc.)

## Notes

Anything else worth remembering across trips — loyalty programs, passes already held (Ontario Parks, Parks Canada), preferred lodging type, must-have travel dates.
