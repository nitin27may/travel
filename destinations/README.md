# Destinations: the laundry list

Every place we might go, as data. One file, one copy, every view generated from it.

| Path | What |
|---|---|
| `destinations.json` | The store. Places and collections. Edit through the tool, not by hand, except to merge notes. |
| `WISHLIST.md` | Generated tree: country > region > area > place, then collections. Regenerated by the hook on every write to the JSON. |
| `inbox/` | Raw captures before or after resolution: screenshots of saved posts, export JSON, batch files for `import`. |

## Hierarchy

```
country   CA                               ISO 3166-1 alpha-2
  region  CA/QC                            province or state, ISO 3166-2 suffix
    area  CA/QC/charlevoix                 park, valley, resort, lake district or town the place sits in
      place CA/QC/charlevoix/mont-du-dome  trail, viewpoint, waterfall, lake, town, activity
```

A collection (road trip, multi-stop idea) is an ordered list of place ids with its own notes and
source, so a 14-stop post is 14 findable places plus one route.

## A place

| Field | Meaning |
|---|---|
| `id`, `name`, `resolved_name`, `kind` | id is derived from the hierarchy and the name; `kind` is one of trail, viewpoint, waterfall, lake, mountain, park, town, city, island, beach, canyon, valley, activity, lodge, drive, museum, lighthouse, region, place |
| `country`, `region`, `area` (+ `_name`) | codes for the id, labels for display |
| `lat`, `lon`, `elevation_m`, `wikidata`, `image` | from the resolver |
| `tags`, `season`, `kid_fit` | capture-time hints; `kid_fit` is yes, strong-kid, no or unknown |
| `stats` | what the source post claimed (km, gain_m, hours); unverified until a research lane confirms |
| `status`, `trip` | idea, shortlisted, planned, visited, dropped; `trip` is the slug once a plan adopts it |
| `verified`, `resolver`, `sources`, `notes`, `added` | provenance |

## Commands

```bash
python3 _system/tools/destinations.py add "Name" --country CA --region QC [--area ...] [--kind ...] [--tags a,b] [--season Sep,Oct] [--kid yes] [--stats '{"km":9}'] [--note ...] [--source URL]
python3 _system/tools/destinations.py import destinations/inbox/2026-10-16-quebec-hikes.json
python3 _system/tools/destinations.py collection add --slug gaspesie-loop --name "Quebec to Gaspesie" --places ID,ID,...
python3 _system/tools/destinations.py validate
python3 _system/tools/destinations.py render
python3 _system/tools/destinations.py list --country CA --q charlevoix
python3 -m pytest _system/tests -q
```

Exit 2 means ambiguous: candidates are printed, re-run with `--pick N`. Exit 1 with `DUPLICATE`
means the place is already there; merge instead of adding.

## Rules

- Capture, do not research. Hours, prices and conditions belong to a trip's research lanes.
- Numbers from a post are stored and flagged, never trusted.
- Wikidata and Nominatim get one request a second with a user agent. Never run two capture
  sessions in parallel.
- The Obsidian `Location.md` (both copies) is retired and points here. Do not write to it.
